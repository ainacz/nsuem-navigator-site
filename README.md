# Навигатор НГУЭУ

Одностраничный сайт со ссылками на ботов в Telegram и MAX.

Сайт: https://ainacz.github.io/nsuem-navigator-site/

Страница работает без сборки и JavaScript. Для изменения текста или ссылок отредактируйте `index.html`. Вместе с ним необходимо сохранять папку `assets`. GitHub Pages публикует корень ветки `main`.

Оформление и оригинальный логотип: [Фирменный стиль НГУЭУ](https://nsuem.ru/smi/style.php).
Шрифт [Unbounded](https://github.com/googlefonts/unbounded) распространяется по лицензии SIL OFL; копия лицензии находится в `assets/Unbounded-LICENSE.txt`.
