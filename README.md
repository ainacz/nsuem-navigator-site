# Навигатор НГУЭУ

Одностраничный сайт со ссылками на ботов в Telegram и MAX.

Сайт: https://ainacz.github.io/nsuem-navigator-site/

Страница работает без сборки и новых библиотек. Встроенный JavaScript управляет каруселью и копированием примеров вопросов. При недоступном копировании появляется выделяемый текст для ручного копирования; раздел дополнительных тем использует обычный `details/summary`. Для изменения текста или ссылок отредактируйте `index.html`. Вместе с ним необходимо сохранять папку `assets`. GitHub Pages публикует корень ветки `main`.

Оформление и оригинальный логотип: [Фирменный стиль НГУЭУ](https://nsuem.ru/smi/style.php).
Шрифт [Unbounded](https://github.com/googlefonts/unbounded) распространяется по лицензии SIL OFL; копия лицензии находится в `assets/Unbounded-LICENSE.txt`.

Проверка карусели в среде с установленным Playwright и Edge: `node check-reviews.cjs http://127.0.0.1:4173/`. Необязательный второй аргумент — исходная выгрузка Markdown для дословного сравнения всех 20 отзывов. Если Playwright установлен вне проекта, задайте `PLAYWRIGHT_PATH` — путь к его модулю.

Проверка возможностей, раскрытия тем и копирования: `node check-features.cjs http://127.0.0.1:4173/`. Необязательный второй аргумент — сохранённый исходный HTML для проверки неизменности первого экрана, всех 21 отзывов и кода карусели.

Для публикации используйте отдельный публичный репозиторий `ainacz/nsuem-navigator-site`. Основной репозиторий проекта остаётся приватным. Коммит и публикация выполняются после подтверждения владельца.
